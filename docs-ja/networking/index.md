# ネットワーク {#networking}

サーバーとクライアントの間の通信は、Mod をうまく実装するための土台です。

ネットワーク通信には、主に 2 つの目的があります。

1. クライアントの見え方を、サーバーの見え方と「同期」させること
    - 座標 ( X, Y, Z ) の花が育った
1. プレイヤーについて何かが変わったことを、クライアントがサーバーに伝える手段を用意すること
    - プレイヤーがキーを押した

これらの目的を達成する最も一般的な方法は、クライアントとサーバーの間でメッセージをやりとりすることです。送受信しやすいよう、これらのメッセージは通常構造化されており、決まった並びでデータを含みます。

NeoForge は、主に [netty][netty] の上に構築された、通信を容易にする仕組みを提供しています。この仕組みは、`RegisterPayloadHandlersEvent` を listen し、特定の型の[ペイロード][payloads]、その読み取り処理、ハンドラ関数をレジストラに登録することで使えます。

[netty]: https://netty.io "Netty Website"
[payloads]: ./payload.md "Registering custom Payloads"
